# Reborn BF – appli Android

Le jeu rebornbf.com dans sa propre appli : plein écran, sans barre d'adresse, avec un panneau pour activer ou couper les bots.

## Installer
Dernière version : **Releases → RebornBF.apk** (à ouvrir sur le téléphone).
Chaque modification envoyée sur `main` recompile l'APK automatiquement (onglet Actions).

## Utiliser
- Bouton doré ☰ (déplaçable) : ouvre le panneau.
- **Bots** : Farm quête (objectif réglable) ou Aventure auto. Un seul à la fois.
- **Mes scripts** : colle un script Tampermonkey (ex. bot d'arène), active/désactive, appui long pour supprimer.
- **Options** : anti-pause, écran toujours allumé, plein écran, filtre HD.
- Retour : page précédente ; sur la première page, l'appli passe en arrière-plan sans fermer le jeu.

Les scripts intégrés sont dans `app/src/main/assets/scripts/`.
